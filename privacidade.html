Política de Privacidade

Última atualização: 1º de junho de 2026

Este documento descreve como o FinanciadoCasal coleta, usa, armazena e protege seus dados pessoais, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

1. Quem somos

O FinanciadoCasal é um aplicativo web de gestão financeira para casais, desenvolvido e operado por Thaislaine Peixeiro, com sede no Brasil.

Para dúvidas sobre esta política ou sobre o tratamento de seus dados, entre em contato pelo e-mail: privacidade@financiadocasal.com.br.

2. Dados que coletamos

Coletamos apenas os dados estritamente necessários para a prestação do serviço:

  • Dados de identificação do casal: ID do casal (gerado pelo usuário), nomes dos cônjuges (opcionais, definidos pelo próprio usuário).
  • Dados financeiros: lançamentos de receitas e despesas, categorias, valores, datas, descrições e comprovantes em imagem enviados para análise por IA.
  • Dados de configuração: chaves de acesso ao Supabase (banco de dados próprio do usuário), chave da API Anthropic (opcional).
  • Dados de pagamento: processados exclusivamente pelo Stripe. O FinanciadoCasal não armazena números de cartão ou dados bancários.
  • Dados técnicos: endereço IP, tipo de navegador e logs de acesso, coletados automaticamente pela infraestrutura da Vercel.

3. Finalidade do tratamento

Seus dados são utilizados exclusivamente para:

  1. Prestar o serviço de gestão financeira (base legal: execução de contrato — LGPD Art. 7º, V).
  2. Processar pagamentos e gerenciar assinaturas via Stripe (base legal: execução de contrato).
  3. Analisar imagens de comprovantes enviadas pelo usuário via IA (base legal: consentimento — LGPD Art. 7º, I).
  4. Enviar comunicações transacionais como confirmação de assinatura e lembretes de contas (base legal: legítimo interesse — LGPD Art. 7º, IX).
  5. Cumprir obrigações legais, quando exigido por lei (base legal: cumprimento de obrigação legal — LGPD Art. 7º, II).

Não utilizamos seus dados para publicidade, venda a terceiros ou criação de perfis comportamentais.

4. Armazenamento e segurança

Seus dados financeiros são armazenados no Supabase, plataforma PostgreSQL com suporte a Row Level Security (RLS). Cada casal acessa exclusivamente seus próprios dados.

  • Os dados são armazenados em servidores localizados na região South America (sa-east-1) no Brasil.
  • A comunicação entre o app e o banco é feita via HTTPS/TLS.
  • Chaves de API são armazenadas no localStorage do dispositivo do usuário e nunca transmitidas para nossos servidores.
  • Imagens de comprovantes enviadas para análise por IA são transmitidas para a API da Anthropic e não são armazenadas por nós.

5. Compartilhamento de dados

Seus dados são compartilhados apenas com os seguintes parceiros essenciais à operação do serviço:

  • Supabase Inc. — banco de dados e autenticação.
  • Stripe Inc. — processamento de pagamentos.
  • Anthropic PBC — análise de imagens de comprovantes (somente quando o usuário ativa a função IA).
  • Vercel Inc. — hospedagem e infraestrutura.
  • Resend Inc. — envio de e-mails transacionais.

Todos os parceiros possuem políticas de privacidade próprias e são contratualmente impedidos de usar seus dados para fins além dos contratados.

6. Direitos do titular (LGPD Art. 18)

Você tem direito a:

  • Confirmação e acesso: saber quais dados temos sobre você.
  • Correção: atualizar dados incompletos ou incorretos.
  • Anonimização, bloqueio ou eliminação: solicitar a remoção de dados desnecessários.
  • Portabilidade: receber seus dados em formato estruturado.
  • Eliminação: solicitar a exclusão completa de sua conta e dados.
  • Revogação do consentimento: retirar consentimento a qualquer momento.
  • Oposição: opor-se a tratamento realizado com base em legítimo interesse.

Para exercer qualquer desses direitos, envie um e-mail para privacidade@financiadocasal.com.br. Responderemos em até 15 dias úteis.

7. Retenção de dados

Mantemos seus dados enquanto sua conta estiver ativa. Após o cancelamento:

  • Dados financeiros são excluídos em até 90 dias.
  • Dados de pagamento (Stripe) seguem a política de retenção do Stripe, exigida por regulamentações financeiras.
  • Logs de acesso são eliminados em até 12 meses.

8. Cookies e rastreamento

O FinanciadoCasal não utiliza cookies de rastreamento ou publicidade. Utilizamos apenas:

  • localStorage no seu dispositivo para armazenar configurações do app (sem envio a terceiros).
  • Cookies técnicos essenciais de sessão, quando aplicável.

9. Crianças e adolescentes

O FinanciadoCasal é destinado exclusivamente a maiores de 18 anos. Não coletamos intencionalmente dados de menores. Caso identificarmos dados de menores, os excluiremos imediatamente.

10. Contato e DPO

Encarregada de Proteção de Dados (DPO): Thaislaine Peixeiro

E-mail: privacidade@financiadocasal.com.br

Autoridade Nacional de Proteção de Dados (ANPD): www.gov.br/anpd

11. Alterações nesta política

Podemos atualizar esta política periodicamente. Alterações relevantes serão comunicadas por e-mail ou aviso no app com pelo menos 15 dias de antecedência. O uso continuado do serviço após o prazo implica concordância com a política atualizada.
